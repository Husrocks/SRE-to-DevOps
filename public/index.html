Essential DevOps Commands Reference

Copy and execute these in your terminal right in this workspace!

Docker Commands Containers

Build Docker image with tag:

docker build -t devops-forge:latest .

Run container in background with port mapping:

docker run -d -p 3000:3000 --name devops-app devops-forge:latest

Inspect live logs & resource stats:

docker logs -f devops-app
docker stats
Docker Compose Multi-Service

Start all services in detached mode:

docker-compose up -d --build

Check status of running stack:

docker-compose ps

Stop and clean up containers & networks:

docker-compose down -v
Kubernetes (kubectl) K8s

Apply all manifests in order:

kubectl apply -f k8s/

View pods, services & HPA:

kubectl get pods,svc,hpa -n devops-lab

Debug a pod or view restart reasons:

kubectl describe pod <pod-name> -n devops-lab
Terraform (IaC) IaC

Initialize plugins & backend:

cd terraform && terraform init

Preview changes before applying:

terraform plan

Apply infrastructure:

terraform apply -auto-approve
