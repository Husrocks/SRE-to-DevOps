Essential DevOps Commands Reference

Copy and use these commands when practicing Docker, K8s, and Git!

Git & GitHub Workflow Version Control

Check status and staged files:

git status

Commit changes with Conventional Commit format:

git commit -m "feat: add chaos simulator"

Push to GitHub main branch:

git push origin main
Docker Container Commands Containers

Build Docker image with tag:

docker build -t myapp:1.0 .

Run container in background with port mapping:

docker run -d -p 8080:80 myapp:1.0

View running containers and live logs:

docker ps
docker logs -f <container-id>
Kubernetes (kubectl) K8s

Apply all manifests in folder:

kubectl apply -f k8s/

View pods, services & autoscalers:

kubectl get pods,svc,hpa

Describe a pod to inspect restart reasons:

kubectl describe pod <pod-name>
GitHub Actions CI/CD CI/CD

Workflow triggers:

on: [push, pull_request]

Workflow file location:

.github/workflows/*.yml

Auto deploy to Pages:

uses: actions/deploy-pages@v4
